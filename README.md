📖 Lexicon

Your intelligent English dictionary.

Lexicon is a sleek, glassmorphism-styled dictionary web app. Search any English word, get its meaning, and jump back to your recent searches with a single click.

🔗 Live Demo: https://muhammadahmad152.github.io/lexicon-dictionary/

Show Image

{screenshot.png}

✨ Features

🔍 Word search: type a word and press Enter or click the search button
🕘 Recent searches: quickly revisit words you looked up before
🧹 Clear All: remove your search history in one click
🎨 Modern glassmorphism UI: gradient background, frosted-glass card, smooth look
🌐 API powered: live data from Wiktionary and Datamuse

🛠️ Tech Stack
HTML5
CSS3 (glassmorphism design)
JavaScript (Vanilla)
Wiktionary API
Datamuse API

📸 How It Works
Enter a word in the search box.
Press Enter or click the search button.
Lexicon fetches the data from Wiktionary and Datamuse and shows the result.
The word is added to Recent Searches so you can open it again anytime.
